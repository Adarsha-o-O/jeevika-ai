# \# JeevikaAI

# 

# AI-driven voice assistant for livelihood mapping and NSQF-aligned skilling recommendations for SC communities under the GIA component of PM-AJAY.

# 

# \## Core Pipeline

# 

# Voice Input

# → Speech Recognition

# → Livelihood Profile

# → Skill Extraction

# → Skill Normalization

# → NSQF Job Role Matching

# → Skill Gap Analysis

# → Training / Employment Recommendations

# → Voice Response

#

# 

# \- `backend/` — FastAPI backend, AI services and recommendation engine

# \- `frontend/` — React frontend and user interface

# \- `data/` — Skills, job roles and course datasets

# \- `docs/` — Architecture and project documentation
